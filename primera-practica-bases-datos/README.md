Práctica de Laboratorio — Introducción a Bases de Datos Relacionales

Herramienta utilizada

Gestor de base de datos: MySQL  
Herramienta: MySQL Workbench  

Descripción

En esta práctica realizamos una introducción al manejo de bases de datos relacionales mediante el lenguaje SQL.

Durante la práctica aprendimos a crear bases de datos y tablas, seleccionar una base de datos de trabajo, insertar registros y realizar consultas para obtener información específica.

También practicamos instrucciones para consultar información mediante `SELECT` y `WHERE`, modificar registros utilizando `UPDATE` y eliminar registros mediante `DELETE`.

Además, realizamos tres ejemplos guiados para comprender el funcionamiento básico de SQL y posteriormente desarrollamos tres ejercicios relacionados con una biblioteca, una tienda y videojuegos.

Finalmente, organizamos los archivos SQL y las evidencias correspondientes para subir nuestro trabajo a un repositorio de GitHub.

Ejemplos :

Los ejemplos realizados durante la práctica se encuentran en la carpeta `Ejemplos`.

- `ejemplos/ejemplo01.sql` (Los 3 ejemplos fueron hechos juntos en un solo archivo)

Ejemplo 1 :

En el primer ejemplo creamos una base de datos llamada `escuela`, creamos la tabla `alumnos`, insertamos información de diferentes alumnos y realizamos una consulta para mostrar todos los registros.

Ejemplo 2 :

En el segundo ejemplo realizamos consultas para mostrar columnas específicas y utilizar condiciones mediante `WHERE`. También modificamos información de un alumno utilizando `UPDATE` y comprobamos los cambios realizados.

Ejemplo 3 :

En el tercer ejemplo practicamos la eliminación de registros utilizando `DELETE`. Primero consultamos la información existente, eliminamos un registro específico y posteriormente realizamos una consulta para comprobar que el registro había sido eliminado.

Ejercicios :

Los ejercicios realizados durante la práctica se encuentran en la carpeta `Ejercicios`.

- `Ejercicios/Ejercicio01.sql`
- `Ejercicios/Ejercicio02.sql`
- `Ejercicios/Ejercicio03.sql`

Ejercicio 1 — Biblioteca :

Creamos una base de datos llamada `biblioteca` y una tabla llamada `libros`. Insertamos diferentes libros y realizamos consultas para mostrar todos los registros, consultar únicamente el título y autor, buscar libros posteriores a un determinado año, modificar información y eliminar un registro.

Ejercicio 2 — Tienda :

Creamos una base de datos llamada `tienda` y una tabla llamada `productos`. Agregamos diferentes productos con su categoría, precio y existencia. Después realizamos consultas, modificamos precios y existencias y eliminamos un producto para comprobar los cambios.

Ejercicio 3 — Videojuegos :

Creamos una base de datos llamada `videojuegos` y una tabla llamada `juegos`. Insertamos diferentes videojuegos indicando su título, género, plataforma y año. Posteriormente realizamos consultas, modificamos la información de algunos registros y eliminamos un videojuego para comprobar los resultados finales.

Evidencias :

Las evidencias de la práctica se encuentran en la carpeta `Evidencias`.

En esta carpeta se incluyen las capturas de pantalla que muestran la ejecución de los comandos SQL y los resultados obtenidos durante la realización de los ejemplos y ejercicios.

Conclusión :

Con esta práctica aprendimos los conceptos básicos de las bases de datos relacionales y el funcionamiento de las principales instrucciones de SQL.

Aprendimos a crear bases de datos y tablas, definir columnas y tipos de datos, insertar registros, consultar información, utilizar condiciones mediante `WHERE`, modificar registros con `UPDATE` y eliminar información mediante `DELETE`.

Una de las principales dificultades fue comprender correctamente la sintaxis de algunos comandos y tener cuidado al modificar o eliminar información. Para resolver estas dificultades revisamos los comandos y realizamos las consultas paso a paso, comprobando los resultados después de cada operación.

También aprendimos la importancia de utilizar `WHERE` en instrucciones como `UPDATE` y `DELETE`, ya que si se omite se pueden modificar o eliminar todos los registros de una tabla.

Finalmente, aprendimos a organizar nuestro trabajo en diferentes archivos `.sql`, guardar las evidencias y preparar el proyecto para entregarlo mediante un repositorio de GitHub.
